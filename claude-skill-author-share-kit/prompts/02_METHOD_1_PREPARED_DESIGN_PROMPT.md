# 방법 1 — 준비된 요구사항·설계서로 스킬 생성

아래 자리표시자를 바꿔 B 세션에서 실행한다. `--mode`와 `--agent`를 생략하면 각각 `full`, `auto`가 적용된다.

```text
/claude-skill-author <스킬명> \
  --design <주 설계서 경로> \
  --design <추가 정책·요구사항 문서 경로>

현재 호출의 목적:
- 기존 설계서를 기준으로 <스킬의 최종 결과>를 만드는 Claude Code 스킬을 생성하거나 개정한다.

보존해야 할 조건:
- <기존 호출 계약·파일 경로·업무 결정>

허용:
- <허용 행동>

금지:
- <금지 행동>

사용자 승인 필요:
- 없음 / <승인 대상>

설계서에 없는 고위험 권한·운영 환경·승인 생략·삭제·외부 전송을 임의로 추가하지 않는다.
설계서 또는 저장소에서 확인할 수 있는 사실은 직접 조사하고, 사용자만 결정할 차단 모호성만 한 번에 질문한다.
```

위 호출은 다음과 같다.

```text
/claude-skill-author <스킬명> --mode full --agent auto --design <설계서 경로>
```

고위험 스킬은 전체 자동 수행 대신 아래처럼 `spec`에서 멈춘다.

```text
/claude-skill-author <스킬명> --mode spec --design <설계서 경로>
```

사람이 `COMMAND_SPEC.yaml`의 권한·승인·복구를 검토한 뒤 `build`, `audit`을 별도로 실행한다.
