# 방법 2 — 자연어 애로사항부터 인터뷰해 스킬 생성

아래 자리표시자를 바꿔 B 세션에서 실행한다. 기본값이 `--mode full --agent auto`이므로 일반 사용에서는 옵션을 붙이지 않아도 된다.

```text
/claude-skill-author <스킬명>

애로사항:
<반복해서 발생하는 문제와 통제하고 싶은 행동을 평범한 말로 작성>

최종 결과:
<사용자가 최종적으로 받아야 하는 산출물과 성공 상태>

허용:
- <허용 행동>

금지:
- <금지 행동>

사용자 승인 필요:
- 없음 / <승인 전에 실행하면 안 되는 행동>

알려진 실패·반례:
- 없음 / <현재 반복되는 실패 사례>
```

위 호출은 다음과 같다.

```text
/claude-skill-author <스킬명> --mode full --agent auto
```

B 세션은 최초 입력을 `SOURCE_REQUEST.md`에 보존하고 저장소를 조사한 뒤, 권한·운영 부작용·승인·복구·업무 완료 기준처럼 사용자만 결정할 차단 항목만 묶어 질문한다. 질문에 답하면 같은 세션에서 설계 작성·설계 감사·spec·build·최종 감사를 계속한다.
